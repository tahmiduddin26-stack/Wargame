## Sources and reproducibility

- Icon: manually authored SVG extending the game's fort/flag identity and ink/paper palette.
- Illustration: **built-in imagegen**, gameplay screenshot as style/subject reference. [Exact final prompt](source/key-art-prompt.txt). This is promotional art, not gameplay footage.
- Lettering: the existing bundled Kalam font placed by [editable HTML layout](source/marketing-layout.html); the source illustration stays unchanged.
- Gallery lettering also uses the bundled Patrick Hand font. [Font licences](../../src/assets/fonts/LICENSES.md).
- Current platform requirements and source links are in [the launch plan](../../docs/store-launch-plan.md). The title is an approved working title, not a cleared trademark.

From the project root, with the production game server running on port 8787:

```powershell
npm run build
node scripts/unit-art-check.mjs
node scripts/capture-store-assets.mjs
node scripts/render-store-art.mjs
node scripts/verify-store-assets.mjs
```

Set `GAME_URL` for another preview address. Capture and export scripts intentionally regenerate this named pack; preserve reviewed exports before rerunning against a later build. The multiplayer preview used for the original captures used an isolated database under `.shots`, and is not a public deployment.

The art renderer also copies the authored icon exports to `public/app-icon-doodlebook*` for the web manifest and favicon. If the icon source changes, rebuild the app after exporting so its offline cache contains the new icons. Store illustration files are kept outside `public` and do not enlarge the installed game bundle.
